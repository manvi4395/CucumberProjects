
# Student Registration Form Filling - Cucumber BDD Framework 

This repository contains an implementation of the Student Registration Form Filling feature in Chrome browser using the Cucumber BDD framework.

The framework is built to follow best practices for test automation, such as the Page Object Model (POM) design pattern, modular architecture, and reusable components.

Note: This is currently in progress.
